Brotato 的角色不是靠「通关次数」解锁的，而是靠完成各种**进度成就**。这些成就的设计很有意思：它们基本上是在引导你去尝试不同的玩法。

这篇把解锁条件按难度分成四层，给出一条不会卡住的路线。

## 第一层：开局就能拿（新手期）

这些条件在你正常玩的过程中会自然达成：

| 角色 | 解锁条件 | 说明 |
| --- | --- | --- |
| 胖子 Chunky | 第一次死亡 | 几乎必然触发 |
| 老人 Old | 击杀 300 敌人 | 前几局就能完成 |
| 幸运儿 Lucky | 收集 300 材料 | 正常游玩即可 |
| 突变体 Mutant | 击杀 2000 敌人 | 约 3~5 局 |
| 多面手 Generalist | 收集 2000 材料 | 约 3~5 局 |
| 病患 Sick | 生命回复降到 -5% | 需要刻意买负面道具 |
| 农夫 Farmer | 收获达到 +200% | 需要专精收获流 |

**建议**：先玩全能者或游侠打通危险 0，然后刻意做「病患」和「农夫」的解锁——这两个条件会强迫你理解回复与收获机制。

## 第二层：需要一点定向操作

| 角色 | 解锁条件 | 提示 |
| --- | --- | --- |
| 幽灵 Ghost | 闪避达到 +60% | 堆闪避类道具，注意上限 |
| 迅捷者 Speedy | 速度达到 +50% | 买鞋类与速度道具 |
| 猎人 Hunter | 射程达到 +300 | 堆射程，配合远程武器 |
| 工程师 Engineer | 同时拥有 5 个炮塔 | 用扳手/螺丝刀铺结构 |
| 医生 Doctor | 单波治疗 200 HP | 医疗武器 + 回复道具 |
| 巫妖 Lich | 最大生命达到 +100 | 血量流 |
| 学徒 Apprentice | 达到 20 级 | 堆经验，别急着通关 |

这一层的共同点是：**你需要为了让某个数字达标而构筑**，而不是为了赢。这恰恰是最好的机制教学。

## 第四层：高难度挑战

| 角色 | 解锁条件 |
| --- | --- |
| 独臂侠 One Armed | 危险 0 通关 |
| 公牛 Bull | 危险 1 通关 |
| 士兵 Soldier | 危险 2 通关 |
| 受虐狂 Masochist | 危险 3 通关 |
| 骑士 Knight | 危险 4 通关 |
| 恶魔 Demon | 危险 5 通关 |
| 重伤者 Wounded | 梦魇难度通关（DLC） |

这一层是纯粹的难度验证。**建议顺序：独臂侠 → 公牛 → 士兵 → 受虐狂 → 骑士 → 恶魔**，因为它们对应的危险等级是递进的。

## 一些容易卡住的解锁条件

**工程师（同时 5 个炮塔）**：需要扳手或螺丝刀起手，并且保持结构不被清掉。建议在低难度做，因为高难度下炮塔很容易被秒。

**潜水员（击杀 1000 个 700 射程外的敌人）**：需要超远射程的狙击类武器，配合猎人式的射程堆叠。这个条件比较磨，建议专门开一局做。

**矮人（单次近战命中 25 个敌人）**：需要大范围近战武器 + 密集的敌群。中后期怪多的时候用横扫类武器比较容易达成。

**浪漫者（以 0 诅咒完成一局）**：DLC 角色，必须完全避开带诅咒的道具。注意有些道具会隐性加诅咒。

## 解锁顺序建议

如果你的目标是「尽快全解锁」，推荐这条路线：

1. 用全能者/游侠打通危险 0，顺手解锁胖子、老人、幸运儿。
2. 专门做「病患」「农夫」「幽灵」「猎人」的解锁，理解四个核心属性。
3. 用工程师做炮塔解锁，用医生做治疗解锁。
4. 依次通关危险 1~5，解锁五个通关角色。
5. 最后做击杀/收集类的累积成就——这些会在前面过程中自然完成大半。

## 关于 DLC 角色

《Abyssal Terrors》的 14 名角色需要拥有 DLC 才能使用，解锁条件大多与诅咒、海军武器、水果、步数等新机制相关。具体清单见 [DLC 内容指南](/guides/dlc-abyssal)。

> 提醒：角色解锁进度是账号级的，但不同平台（Steam/主机/移动端）不互通。
