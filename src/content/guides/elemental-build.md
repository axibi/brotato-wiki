元素流是 Brotato 里最「反直觉」的流派：它的单次伤害很低，但总伤害很高；它不需要贴着敌人打，但需要敌人活着足够久。

理解燃烧，就理解了元素流。

## 燃烧是怎么工作的

元素武器命中后会给敌人附加**燃烧**状态，在接下来的一段时间内持续掉血。燃烧的伤害由**元素伤害**缩放。

这意味着两件事：

1. 元素流的伤害是**延迟生效**的，你需要「先点火，再等它烧」。
2. 敌人死得太快，燃烧的伤害就浪费了。

所以元素流最怕的不是高血量敌人，而是「你秒得太快」——听起来很矛盾，但这决定了元素流的武器选择：**低单发、高触发频率**的武器比高单发武器更适合。

## 元素流的两套打法

**打法一：纯元素（火焰喷射器、法杖、冰锥）**
所有伤害来自元素，属性全堆元素伤害。优点是纯粹、成长线性；缺点是对高血量单体乏力。

**打法二：点火 + 物理收割（厨师流派）**
用火把/火焰喷射器点火，再用高物理伤害武器收割被点燃的目标。厨师（Chef）对燃烧目标有 +200% 非元素伤害，是这套打法的专属角色。

第二种打法的上限更高，因为它同时利用了元素与物理两个乘区。

## 属性优先级

1. **元素伤害**：核心乘区。
2. **攻速**：提高点燃频率，让更多敌人同时燃烧。
3. **范围（爆炸范围/武器范围）**：让燃烧覆盖更多目标。
4. **全局伤害**：后期补。
5. **生存**：元素流通常站得较远，生存压力小于近战。

## 武器选择

| 武器 | 特点 |
| --- | --- |
| 火把 Torch | 近战点燃，最便宜的燃烧源 |
| 火焰喷射器 Flamethrower | 持续喷射，范围点燃 |
| 法杖 Wand | 追踪弹道，稳定触发 |
| 冰锥 Icicle | 冰系远程，适合稳定输出 |
| 闪电刀 Lightning Shiv | 高攻速元素近战 |
| 木板 Plank | 同时吃近战/元素/工程，灵活 |

## 核心道具

- **沸水 / 燃料罐**：元素伤害主力。
- **蛇**：让燃烧蔓延到附近敌人，是元素流的关键质变道具。
- **冰封之心**：武器伤害额外吃元素加成，把物理武器也变成元素武器。
- **希腊火**：燃烧额外造成当前生命百分比伤害，对高血量目标极强。
- **营火 / 蜡烛**：元素伤害 + 回复，兼顾生存。

## 角色适配

- **法师 Mage**：元素伤害 +25%，蛇 + 香肠开局，最纯粹的元素角色。
- **厨师 Chef**：燃烧目标增伤，点火收割流。
- **工匠 Artificer**：爆炸 + 工具武器，元素转爆炸范围。
- **科技法师 Technomage**：元素与结构互养。
- **德鲁伊 Druid**：幸运 + 水果，走暴击元素混合。

## 元素流的三个误区

**误区一：堆元素伤害就够了。**
元素伤害只放大燃烧的数值，不放大「覆盖范围」。没有范围，你一次只能烧一个敌人。

**误区二：用高单发武器点火。**
高单发武器攻速慢，点燃频率低，大量敌人在没被点燃前就贴到脸上了。

**误区三：忽视「燃烧激活速度」。**
部分道具会加快或减慢燃烧触发。冰封之心会显著减慢燃烧速度——它适合「武器伤害吃元素」的构筑，不适合纯燃烧流。

## 什么时候不该玩元素流

如果你的角色有「元素伤害修正 -75%」（厨师）或「元素修正 -100%」（赛博格），说明设计者不想让你走纯元素。这时候应该把元素当作**辅助乘区**，而不是主乘区。

> 元素流是一种「耐心流」：它不追求瞬间爆发，而是让整片战场持续掉血。学会等，是这个流派最重要的一课。
