打完第 20 波 Boss 后，游戏并不会结束——你可以继续进入无尽模式。这里没有终点，只有不断膨胀的敌人和越来越离谱的数值。

## 无尽模式的本质

无尽模式是一个**指数对抗**：

- 敌人血量、伤害随波次指数增长。
- 你的成长必须也是指数的，否则几波后就会被甩开。

线性成长（比如每波 +5 近战伤害）在无尽模式里毫无意义。你需要的是**乘数型成长**。

## 四条可持续成长路线

**路线一：材料 → 属性 → 伤害（收获流）**
通过极高的收获值，每波获得海量材料，再转化为属性。代表：农夫、储蓄者。
优点是稳定；缺点是需要很长的铺垫期。

**路线二：百分比伤害（巨人腰带、希腊火）**
按敌人当前生命百分比造成伤害，天然对抗血量膨胀。这是无尽模式最重要的机制之一。

**路线三：血量流（胖子、恶魔）**
最大生命可以无限增长，而部分武器的伤害按最大生命缩放，形成「血量 → 伤害」的乘数循环。

**路线四：诅咒/特殊缩放**
DLC 的诅咒机制可以让武器伤害随诅咒值无限放大，是当前版本无尽模式的上限路线之一。

## 关键道具

无尽模式有几个「必拿」级别的道具：

| 道具 | 作用 |
| --- | --- |
| 巨人腰带 | 暴击造成敌人当前生命 10% 伤害 |
| 希腊火 | 燃烧造成敌人当前生命 10% 伤害 |
| 土豆发射器 | 伤害随最大生命缩放 |
| 存钱罐 / 收获类 | 材料复利 |
| 沙漏 | 回溯波数（谨慎使用） |
| 再生药水 / 缓步动物 | 容错 |

其中巨人腰带与希腊火是「反血量膨胀」的核心，越到后期越重要。

## 属性优先级的变化

无尽模式中，属性优先级与标准局不同：

1. **百分比伤害 / 特殊缩放**：唯一能跟上敌人膨胀的东西。
2. **最大生命**：既是生存，也是部分武器的伤害源。
3. **攻速**：提高触发频率（暴击、燃烧、百分比伤害）。
4. **护甲/闪避**：后期敌人的伤害会高到「减伤也扛不住」，但仍然是必要的缓冲。
5. **普通伤害属性**：边际收益迅速下降。

## 性能与手感

无尽模式后期会出现大量敌人、弹幕与特效，游戏帧率可能下降。这不是你的错觉，而是引擎负载问题。建议：

- 少用会产生大量特效的道具（爆炸类、召唤类）。
- 武器数量不要太多，6~12 把足够。
- 速度不要堆太高，否则走位会失控。

## 什么时候该结束

无尽模式没有「通关」，但有一个心理上的终点：**当你每波需要 10 分钟以上，且必须全程全神贯注时**，继续下去的意义就不大了。

另一个判断标准：如果你的构筑依赖某一件道具（比如没拿到巨人腰带），那这局的无尽上限就很有限，不如重开一局专门做无尽构筑。

## 一个无尽流的开局模板

1. 选择一个有「无限成长」机制的角色：农夫（收获）、胖子（血量）、恶魔（血量经济）。
2. 前 20 波按标准局打，目标是「稳定通关」而不是「速通」。
3. 第 20 波后开始转型：把资源全部投入成长引擎（收获/血量/诅咒）。
4. 拿到百分比伤害道具后，逐步替换普通输出道具。
5. 保持至少一件保命道具，防止意外。

> 无尽模式的乐趣不在于「打到多少波」，而在于「看着自己的构筑逐渐失控」。它更像一个沙盒，而不是一个挑战。
