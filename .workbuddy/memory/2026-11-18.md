## 土豆兄弟中文百科：上线与 Git 集成

- 技术栈：Astro 5.18 + TS + Tailwind 4（CSS-first）+ Markdown Content Collections + JSON 数据，纯静态 SSG。
- 数据流水线：`scripts/parse-wiki.mjs`（解析 MediaWiki 模板 → `src/data/raw/*.raw.json`）→ `src/data/i18n/*.json` 中文层 → `scripts/build-data.mjs` → `src/data/{characters,weapons,items}.json`。可用 `npm run data:all` 重跑。
- 规模：64 角色 / 78 武器 / 247 道具 / 18 篇攻略 / 4 条版本记录，构建 420 页。

### 部署结论（重要）

- 线上地址：https://brotato-wiki.pages.dev
- 代码仓库：https://github.com/axibi/brotato-wiki （Public）
- Cloudflare Pages 项目 `brotato-wiki` 已接入 GitHub App（Cloudflare Workers and Pages），生产分支 `main`，构建命令 `npm run build`，输出 `dist`，自动部署已启用 → **push 到 main 即自动构建发布**。

### 踩过的坑

- 直接在控制台上传 zip 会把路径分隔符变成 `\`（`characters\index.html`），导致除根目录外全部 404；必须用 `wrangler pages deploy` 或 Git 集成。
- `wrangler login` 会尝试打开系统默认浏览器；改用 `wrangler login --browser false` 取链接，在已登录的 Chrome 里点 Authorize。
- GitHub 添加 SSH 公钥需要 sudo 模式，无法代操作；用户自行添加后（`~/.ssh/id_ed25519`，指纹 VWULFj8s…）即可 `git push`。已在 `~/.ssh/config` 写入 github.com 的 IdentityFile。
- Cloudflare 连接 Git 仓库时，仅授权 OAuth 不够，还需安装 GitHub App 并勾选仓库。
- 本地首次推送用 `git push --force-with-lease` 覆盖了网页上传留下的碎片提交。

### 维护

- 数据更新：`npm run data:all` → 检查 `src/data/*.json` 变化 → build → push。
